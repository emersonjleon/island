# Stage 1 rules: who does what (WP5, WP6, WP7)

Three packages fill the rule stubs in `engine/rules/` **in parallel**. Each owns only its modules and its tests. They talk only through the engine core (`engine/game.py`): registered command/timer handlers, `on_new_game` / `after_step` hooks, and signals (`emit` / `@connect`). Rule modules must not import each other at module level (lazy imports inside functions are allowed when a direct call is listed below).

Read the engine core first: `engine/state.py`, `scheduler.py`, `commands.py`, `events.py`, `errors.py`, `game.py`, `views.py`, `codec.py`, `engine/tests/fixtures.py`. Settings: `engine/settings/models.py`. Board: `engine/board/{coords,topology,model,generator}.py`.

## Core contract (from WP4)
- Command handler `fn(state, seat, cmd, now) -> list[Event]`: validate everything first, then mutate; never raise `RuleError` after mutating. Use `game.set_check_rejects(True)` in tests.
- Timer handler `fn(state, timer, now) -> list[Event]`, never raises `RuleError`; `state.now_ms` equals the timer's due time.
- Hooks `fn(state, now) -> list[Event]`; `after_step` hooks must be no-ops when nothing relevant changed.
- In tests, call `game.advance(state, now)` before each `game.apply(state, seat, cmd, now)` (the core refuses `apply` with an unfired due timer).
- Every number from settings. Integer maths only. All randomness via `state.rng`.
- Timer kinds: `game.TIMER_DICE_ROLL`, `game.TIMER_SETTLER_ARRIVE`, `game.TIMER_CONSTRUCTION_DONE`.
- Signals: `game.SIG_SETTLER_DEPARTING` (kwargs `settler, vertex`), `game.SIG_BUILT` (kwargs `seat, kind, target, setup, construction`; emitted before the `built` event is created).

## WP5 — movement (`engine/board/walkgraph.py`, `engine/rules/movement.py`)
- Walk graph: nodes = land vertices (touch ≥1 land hex); edges = land edges (touch ≥1 land hex). Sea is impassable.
- Edge time = `settlers.ms_per_edge`, or `ms_per_edge * 100 // settlers.road_speed_pct` when the edge carries the walking player's **own finished road**. Computed when the settler *enters* the edge.
- Pathfinding: Dijkstra/A* with integer costs, deterministic tie-breaking.
- Landing points (`settlers.landing == "even_coast"`): order the coastal vertices along the outer coastline cycle, choose `players × start_count` evenly spaced points with a random offset from `state.rng`, assign to seats in seat order.
- `on_new_game` hook (order 50): create `settlers.start_count` settlers per player at landing points (`state.next_id("settler")`, `player.settler_ids`), emit `SettlerLanded`.
- Command `move_settler`: own settler, target is a land vertex, reachable. `replace`: drop the queued path; if mid-edge, finish the current edge and continue from its end vertex. `append`: path from the end of the current queue. Emit `SettlerPath` (full remaining path).
- Walking: when a settler leaves a vertex, first `emit(state, SIG_SETTLER_DEPARTING, now, settler=id, vertex=v)` (construction cancels builds that settler was doing), then set `step`, schedule `settler_arrive`, emit `SettlerStepEvent`. On arrival: update `vertex`, emit `SettlerArrived`, start the next edge if the path continues.
- A settler that is removed (see WP6) has its timer cancelled by WP6; movement must tolerate a timer whose settler no longer exists (ignore it).
- Expose plain functions others may call lazily: `walkgraph.shortest_path(state, seat, from_v, to_v)`, `movement.settler_at_rest(state, settler_id) -> int | None` (vertex if standing still with an empty path, else None).

## WP6 — setup, placement, construction (`engine/rules/setup.py`, `placement.py`, `construction.py`)
- `on_new_game` hook (order 60): give each player `economy.starting_materials` (taken from the bank when `starting_materials_from_bank`), emit `StartingMaterials`.
- Placement rules (pure functions in `placement.py`, used by construction and by the `buildable` provider):
  - Settlement: land vertex; empty; distance rule (no building on a neighbouring vertex); piece left. **Setup** (player's `setup_remaining[settlement] > 0` and not `setup_done`): no road connection needed. **Network** (after own setup): must touch the player's own finished road, and the player's setup must be done (`setup.network_build_during_setup` false).
  - Road: land edge; empty; piece left. Setup road: must touch the player's own *finished* setup settlement (`last_setup_settlement` when `setup.road_touches_new_settlement`). Network road: touches the player's own road or building, not continuing *through* a vertex occupied by an opponent's building.
  - City: own finished settlement; city piece left; after own setup.
  - Builder: `settlers.builder_required == "setup_only"` → during the player's setup, a settler of that player must stand at the target vertex (settlement) or at an endpoint of the edge (road), at rest (`movement.settler_at_rest`). After setup no builder is needed.
- Command `build`: check placement + cost (`economy.costs`) + pieces; pay into escrow (`Construction.paid`), reserve the piece, schedule `construction_done` after `build.time_ms[kind]` (network builds timed when `build.network_builds_timed`, else complete immediately), emit `ConstructionStarted`. Setup builds use normal costs, paid from starting materials.
- Command `cancel_build`: own construction → refund `build.refund_pct` of escrow (integer floor per resource), return the piece, emit `ConstructionCancelled(reason="cancelled")`.
- Listen to `SIG_SETTLER_DEPARTING`: cancel that settler's in-progress constructions (`reason="builder_left"`, full refund per `refund_pct`).
- `construction_done` timer: re-check placement (ignoring cost — already paid). If no longer legal → cancel with refund (`reason="conflict"`). Else place the building/road, update setup counters, `emit(SIG_BUILT, ...)`, emit `Built`. Then cancel every other in-progress construction that is now illegal (same vertex or neighbouring vertex for settlements, same edge for roads) with `reason="conflict"` and refund. First to finish wins; equal times resolve by timer order.
- Setup completion per player: after a setup settlement completes, grant starting resources if it is within `economy.starting_resources.granting_settlements`: `cards_per_hex` of each adjacent producing hex's resource (fishing grounds included when `include_fishing`; desert/robber don't block), taken from the bank only if available; emit `StartingResources`. When the player's `setup_remaining` reaches zero: `setup_done = True`, emit `SetupComplete`; if `settlers.leave_after_setup`, remove that player's settlers (cancel their timers, delete from `state.settlers` and `player.settler_ids`), emit `SettlerLeft`.
- Clock start: on the **first completed settlement of anyone** (`setup.start_trigger == "first_settlement"`), if not `state.clock_started`: set it, `phase = "running"`, schedule `TIMER_DICE_ROLL` at `now + clock.roll_interval_ms`, set `next_roll_at` and `roll_timer_id`, emit `ClockStarted`. The dice handler (WP7) does the rest.
- `buildable` provider: register with `views.register_buildable_provider`; an `after_step` hook (order 200) emits a private `Buildable` event per seat when its set changed (cache in `state.buildable_cache`). During setup it lists legal targets ignoring the builder position (the client guides the settler); after setup, what the player can legally build and afford.

## WP7 — dice, production, robber, trade, victory (`engine/rules/{dice,production,robber,trade,victory}.py`)
- `dice_roll` timer: roll `clock.dice_count` dice of `clock.dice_sides` via `state.rng.dice`; record `last_roll`/`dice_history`; schedule the next roll at `timer.due_ms + roll_interval_ms` (no drift; plus `pause_after_seven_ms` after a robber roll); emit `DiceRolled`. If sum == `clock.robber_roll` → `robber.on_seven`; else `production.produce(roll)`. Direct lazy calls between these modules are fine (same package).
- Production: for each hex from `board.producing_hexes(roll)` except the robber's hex, every adjacent finished settlement gets `production_per.settlement`, city `production_per.city`. Bank shortage rule (`economy.bank.shortage_rule == "classic"`): if the bank cannot pay everyone owed a resource, nobody gets it — unless only one player is owed it, who gets what is left. Emit one `Produced` event (with `skipped` reasons) and private `Hand` updates as needed.
- Robber on seven (`robber.enabled`): targets = players whose hand total > `card_limit` when `require_over_limit`, AND (if `require_adjacent`) who have a building next to the robber hex judged before the move. Each target loses `floor(total * steal_pct / 100)` random cards (draw one card at a time uniformly from the hand via `state.rng`); stolen cards go to the bank when `stolen_to_bank`. Emit `RobberStole` per target. Then move the robber to a random neighbouring land hex (deserts allowed per `may_enter_desert`, fishing grounds only when `may_enter_fishing`); if none, it stays; emit `RobberMoved`. Knights are stage 2.
- Command `bank_trade`: allowed for a player during setup only if `setup.bank_trade_during_setup`. Ratio = best of `economy.trade.bank_ratio`, generic harbor `generic_ratio`, and specific harbor for the given resource (`specific_ratio`), where harbors count only if the player owns a finished settlement or city on one of the harbor's vertices and `trading.harbor_trade` is on. `give` must equal `ratio × get`; the bank must hold the requested resource. Emit `Traded` and private `Hand`.
- Victory: listen to `SIG_BUILT` → settlement +`victory.building_points.settlement`, city → `building_points.city - building_points.settlement` added; emit `Points`. `after_step` hook (order 900): if any player's points ≥ `victory.target` → `phase = "finished"`, `winner` (ties: the first to reach it — keep it simple: lowest seat among those at max points, document), `finished_at`, cancel the dice timer, emit `GameOver`.
