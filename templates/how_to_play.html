{% blocktranslate trimmed %} Ages of the Island is a race to build on an island, in real time. There are no turns: everyone plays at once while a clock rolls the dice for all. {% endblocktranslate %}

{% blocktranslate trimmed %} Start with the classic game. The variations you can add when you create a game, such as ages, settlers or a hidden island, have their own page. {% endblocktranslate %}

{% translate "Goal" %}

{% blocktranslate trimmed with target=s.victory.target %} The first player to reach {{ target }} points wins. You earn points with settlements, cities, awards and some developments. {% endblocktranslate %}

{% translate "The start: your settler" %}

  1. {% translate "Your settler lands on the coast. Walk it from corner to corner to the spot you like." %}
  2. {% blocktranslate trimmed with settlements=s.setup.settlements roads=s.setup.roads %} Build your first {{ settlements }} settlements and {{ roads }} roads. You already have the materials for them, and each road goes next to the settlement you just built. {% endblocktranslate %}
  3. {% translate "A settlement needs a free corner: no other settlement may stand on a neighbouring corner." %}
  4. {% translate "Each of your first two settlements gives you one resource from every hex around it." %}
  5. {% translate "If someone finishes building on that corner first, your build is cancelled and refunded. Be quick!" %}

{% translate "While a player is still building their starting settlements and roads, the robber never steals from them." %}

{% translate "Dice and resources" %}

{% blocktranslate trimmed with seconds=roll_seconds %} The clock starts with the first settlement and rolls two dice every {{ seconds }} seconds. Every hex showing the rolled number gives its resource to each settlement around it (2 to a city). {% endblocktranslate %}

{% translate "Forests give lumber, hills brick, pastures wool, fields grain, mountains ore and fishing grounds fish. The desert gives nothing." %}

{% translate "6 and 8 come up most often; 2 and 12 rarely. The dots under each number show how likely it is." %}

{% translate "The robber" %}

{% blocktranslate trimmed with limit=s.robber.card_limit pct=s.robber.steal_pct %} When the dice show a 7 nothing is produced. The robber takes {{ pct }}% of the resources of everyone holding more than {{ limit }}, then moves by itself to a neighbouring hex. The hex where it stands produces nothing. {% endblocktranslate %}

{% translate "Tip: spend or trade your resources before a 7 comes." %}

{% translate "Trading" %}

{% blocktranslate trimmed with ratio=s.economy.trade.bank_ratio generic=s.board.harbors.generic_ratio specific=s.board.harbors.specific_ratio %} Trade {{ ratio }} resources of one kind with the bank for 1 of any other. With a settlement or city on a harbor you trade at {{ generic }}:1, or {{ specific }}:1 for that harbor's resource. {% endblocktranslate %}

{% translate "Developments and awards" %}

{% blocktranslate trimmed with cost=dev_card_cost %} A development costs {{ cost }}. It is drawn at random and can be used from the roll after you bought it, one per roll. They never run out. {% endblocktranslate %}

  • {% blocktranslate trimmed with dist=s.robber.knight_max_distance %} Knight: move the robber up to {{ dist }} hexes and steal a resource from a player there. {% endblocktranslate %}
  • {% translate "Road building: two free roads." %}
  • {% translate "Year of plenty: two resources of your choice from the bank." %}
  • {% translate "Monopoly: all of one resource from every player." %}
  • {% translate "Victory point: one point when used." %}

{% blocktranslate trimmed with road=s.victory.longest_road.min road_points=s.victory.longest_road.points army=s.victory.largest_army.min army_points=s.victory.largest_army.points %} The longest road (at least {{ road }} segments) is worth {{ road_points }} points, and the largest army (at least {{ army }} knights played) another {{ army_points }}. {% endblocktranslate %}

{% translate "Controls" %}

{% translate "Computer" %}

  • {% translate "WASD or the arrow keys walk your settler; Shift + WASD moves the camera; the mouse wheel zooms." %}
  • {% translate "Right-click a corner or edge to walk there or build." %}
  • {% translate "R builds a road, E a settlement, C a city; T opens trading. You can change the keys in the game." %}

{% translate "Phone or tablet" %}

  • {% translate "Tap a spot on the map to walk there or build." %}
  • {% translate "Drag to move the map, pinch to zoom; the buttons at the bottom build and trade." %}

{% translate "In the game, the Guide panel under the dice clock tells you the next step, and the ? button repeats these rules." %}

{% translate "Tips for your first game" %}

  • {% translate "Choose corners touching different resources and numbers like 5, 6, 8 and 9." %}
  • {% translate "Brick and lumber build roads; grain and ore build cities. You need both kinds." %}
  • {% translate "Build roads toward free corners before someone else takes them." %}
  • {% translate "Play against bots first: the host can add them in the game room." %}
